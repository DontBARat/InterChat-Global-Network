# 🔐 InterChat Global Network v5.5

> **"We forced AI to build an encrypted retro-messenger under the Half-Life OST on potatophones"**

InterChat is an ultra-secure, decentralized, and encrypted crypto-messenger built from scratch in Python using pure sockets. The interface is meticulously designed to recreate the raw, nostalgic aesthetics of Windows 2000 and early ICQ clients.

---

## 📦 FOR USERS (How to Join the Chat)
Ordinary chat agents **DO NOT need to install Python** or any development environments. The client is fully compiled and autonomous!

1. Download the compiled `InterChat.exe` archive.
2. Ensure there is a text file named `config.txt` in the same folder.
3. Write your master server IP on the first line and the port on the second line (e.g., `127.0.0.1` and `12345`).
4. Run `InterChat.exe`, select your language, and engage in secure global communications.

---

## 💻 FOR ADMINISTRATORS (How to Host a Master Node)
If you want to host your own secure server node for international communications, you **MUST install Python** on your machine.

### 🛠️ Step-by-Step Server Setup:
1. **Download Python:** Go to the official website [python.org](https://python.org) and download the latest version for your Operating System.
2. **Install Python:** Run the official installer. **CRITICAL SECURITY STEP:** Make sure to check the box that says **"Add Python to PATH"** before clicking install!
3. **Get the Code:** Download the `server.py` file from this repository.
4. **Launch the Node:** Open your terminal or Windows Command Prompt (`cmd`), navigate to the server directory, and execute:
   ```bash
   python server.py
   ```
5. Done! Your master node is now online and routing encrypted international traffic on port `12345`.

## 🚀 Key Technical Features
* **Military-Grade XOR Encryption (Key: 42):** Complete protection against NSA, FBI, and CIA packet sniffing. The central master node routes raw encrypted bytes without reading the sensitive message contents.
* **Geopolitical Chat Rooms:** Switch communication tunnels dynamically between regional channels (Russia, USA, United Kingdom, Canada, Germany, Israel) and the global United Nations (UN) headquarters.
* **The "Great Firewall of China" Excluded:** The platform is explicitly optimized for the open Web. Due to the Golden Shield restrictions, China is excluded from the geopolitical room grid.
* **Dynamic Language Translation:** Switch between English and Russian instantly inside the live application window. The interface and the geopolitical countries list adapt on the fly.
* **Anti-Brony Firewall:** A built-in semantic filter automatically drops any incoming or outgoing messages containing brony/pony content (System Error 403).
